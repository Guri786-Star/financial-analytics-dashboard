# Financial Analytics Dashboard

## Files
- app.py: Streamlit dashboard
- requirements.txt: Python dependencies

## Run locally
1. Install Python.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py

The app starts with synthetic demonstration data. Upload a CSV
containing Date and Close columns to analyze your own dataset.
If Asset is absent, the app assigns one asset label.

All synthetic prices are illustrative, not real market data.
